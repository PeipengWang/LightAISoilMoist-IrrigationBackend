# 水泵控制命令下发操作文档

> 创建日期：2026-07-09
> 用途：通过 OneNET REST API 对农业环境监测终端下发水泵开关控制命令

---

## 1. 概述

通过 OneNET 物模型 REST API 的 `set-device-desired-property` 接口，向设备 `device`（产品 `FeGVC46Lne`）下发水泵开关命令。

- **属性标识符**：`F`
- **取值**：`1` = 开启水泵，`0` = 关闭水泵
- **数据类型**：int（枚举）

## 3. API 接口说明

### 3.1 设置设备期望属性（下发命令）

| 项目 | 内容 |
|------|------|
| **接口地址** | `POST https://iot-api.heclouds.com/thingmodel/set-device-desired-property` |
| **Content-Type** | `application/json` |
| **鉴权方式** | Authorization 头，HMAC-SHA256 签名 |

**请求体结构：**

```json
{
    "product_id": "FeGVC46Lne",
    "device_name": "device",
    "params": {
        "F": 1
    }
}
```

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `product_id` | String | 是 | 产品 ID |
| `device_name` | String | 是 | 设备名称 |
| `params.F` | int | 是 | 水泵状态：1=开启，0=关闭 |

**成功响应：**

```json
{
    "code": 0,
    "msg": "success",
    "data": {}
}
```

**失败响应：**

```json
{
    "code": 非0,
    "msg": "错误描述"
}
```

### 3.2 查询设备属性（查看状态）

| 项目 | 内容 |
|------|------|
| **接口地址** | `GET https://iot-api.heclouds.com/thingmodel/query-device-property?product_id=FeGVC46Lne&device_name=device` |
| **鉴权方式** | Authorization 头（同上） |

**成功响应结构：**

```json
{
    "code": 0,
    "msg": "success",
    "data": [
        {"identifier": "A", "value": "7.0"},
        {"identifier": "B", "value": "45"},
        {"identifier": "F", "value": "1"},
        ...
    ]
}
```

## 4. 鉴权 Token 生成

### 4.1 算法参数

| 参数 | 值 |
|------|-----|
| **version** | `2022-05-01` |
| **method** | `sha256` |
| **res** | `products/FeGVC46Lne/devices/device` |
| **et** | 当前 Unix 时间戳 + 3600（1小时过期） |

### 4.2 签名步骤

```
1. 构建待签名字符串 org:
   org = et + "\n" + method + "\n" + res + "\n" + version

2. 使用设备 AccessKey 的 Base64 解码值作为 HMAC-SHA256 密钥

3. 对 org 进行 HMAC-SHA256 签名

4. 签名结果进行 Base64 编码 + URL 编码

5. 资源路径 res 进行 URL 编码

6. 拼接 Authorization 头:
   version=2022-05-01&res={url_encoded_res}&et={et}&method=sha256&sign={url_encoded_sign}
```

### 4.3 Java 实现参考

```java
String version = "2022-05-01";
String res = "products/" + PRODUCT_ID + "/devices/" + DEVICE_NAME;
String et = String.valueOf(System.currentTimeMillis() / 1000 + 3600);
String org = et + "\n" + "sha256" + "\n" + res + "\n" + version;

byte[] key = Base64.getDecoder().decode(ACCESS_KEY);
Mac mac = Mac.getInstance("HmacSHA256");
mac.init(new SecretKeySpec(key, "HmacSHA256"));
byte[] signBytes = mac.doFinal(org.getBytes(StandardCharsets.UTF_8));

String sign = URLEncoder.encode(
    Base64.getEncoder().encodeToString(signBytes), StandardCharsets.UTF_8);
String resEnc = URLEncoder.encode(res, StandardCharsets.UTF_8);

String token = String.format("version=%s&res=%s&et=%s&method=sha256&sign=%s",
    version, resEnc, et, sign);
```

## 8. 注意事项

1. **ClientID 冲突**：OneNet 不允许两个连接使用相同的 ClientID。物理设备已作为设备终端建立连接，后端只能使用应用身份（应用级 MQTT）或 REST API，**不能使用设备身份 MQTT 连接**。

2. **期望值 vs 上报值**：`set-device-desired-property` 设置的是"期望值"，需要通过 `query-device-property` 确认设备是否已上报该值。可能存在延迟。

3. **Token 有效期**：API Token 有效期为 1 小时（3600 秒），每次请求都会重新生成。

4. **AccessKey 使用**：本测试使用**设备级 AccessKey** 进行鉴权，资源路径为 `products/{pid}/devices/{dname}`。若使用 Master-APIKey，资源路径为 `products/{pid}`，二者不通用。

5. **超时设置**：HTTP 连接超时和读取超时均为 10 秒，网络环境差时可能需要调整。

## 9. 故障排查

| 现象 | 可能原因 | 解决方案 |
|------|---------|---------|
| `code != 0` | 设备不在线 / 属性不存在 | 检查设备是否在线，确认属性标识符正确 |
| HTTP 非 200 | 鉴权失败 / URL 错误 | 检查 AccessKey 是否正确，Token 格式是否正确 |
| 返回空响应 | 网络不通 / 防火墙拦截 | 检查是否能 ping 通 `iot-api.heclouds.com` |
| 设置成功但设备无反应 | 设备端未处理期望值 / 设备离线 | 检查设备端代码是否正确读取期望属性 |
| `Connection refused` | 网络问题 | 检查代理/VPN 设置 |
