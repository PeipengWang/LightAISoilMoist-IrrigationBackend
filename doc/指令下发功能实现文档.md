# 指令下发功能实现文档

## 概述

通过后端 REST API 向 OneNet 平台下发设备期望属性值，实现对农业监测终端的远程控制。

## 实现架构

```
前端/客户端 → POST /api/command → DeviceController → OneNetApiClient.setDesiredProperty()
                                                              ↓
                                                    POST OneNet REST API
                                                    /thingmodel/set-device-desired-property
                                                              ↓
                                                      OneNet 平台 → 设备终端
```

## 可写属性清单

设备 `device`（产品 `FeGVC46Lne`）当前支持以下属性的指令下发：

| 标识符 | 名称 | 类型 | 取值范围 | 说明 |
|--------|------|------|---------|------|
| F | 水泵状态 | enum/int | `0`=关闭, `1`=开启 | 控制灌溉水泵开关 |
| I | PH阈值低 | string | 如 `"5.5"` | 设备端 pH 下限告警阈值 |
| J | PH阈值高 | string | 如 `"8.5"` | 设备端 pH 上限告警阈值 |
| K | 土壤湿度阈值低 | string | 如 `"30"` | 设备端湿度下限告警阈值（%） |
| L | 土壤湿度阈值高 | string | 如 `"70"` | 设备端湿度上限告警阈值（%） |

## API 接口

### POST /api/command

**描述**：向指定设备下发期望属性值。

**Content-Type**：`application/json`

**请求体**：

```json
{
  "device_name": "device",
  "identifier": "F",
  "value": 1
}
```

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| device_name | string | 是 | 目标设备名，当前仅支持 `device` 和 `DHT11` |
| identifier | string | 是 | 属性标识符，如 F/I/J/K/L |
| value | int/string | 是 | 属性值，类型需与目标属性匹配 |

### 响应示例

#### 成功（水泵开启）

```json
{
  "device_name": "device",
  "identifier": "F",
  "property_name": "水泵状态",
  "value": 1,
  "value_desc": "开启",
  "result": {
    "code": 0,
    "msg": "SUCCESS"
  }
}
```

#### 成功（设置湿度阈值）

```json
{
  "device_name": "device",
  "identifier": "K",
  "property_name": "土壤湿度阈值低",
  "value": "30",
  "result": {
    "code": 0,
    "msg": "SUCCESS"
  }
}
```

#### 失败 — 设备不存在

```json
{
  "error": "设备 xxx 不存在",
  "available_devices": ["DHT11", "device"]
}
```

#### 失败 — 属性不存在

```json
{
  "error": "属性 X 不存在于设备 device",
  "available_identifiers": ["A", "B", "C", "D", "E", "F", "G", "H", "I", "J", "K", "L", "M", "N", "O"]
}
```

#### 失败 — 属性为只读

```json
{
  "error": "属性 A(PH值) 为只读属性，不可下发",
  "writable_identifiers": ["F(水泵状态)", "I(PH阈值低)", "J(PH阈值高)", "K(土壤湿度阈值低)", "L(土壤湿度阈值高)"]
}
```

#### 失败 — 参数缺失

```json
{
  "error": "device_name 不能为空"
}
```

#### 失败 — 类型不匹配

```json
{
  "error": "属性 F 需要整数类型，收到: abc"
}
```

## 调用示例

### cURL

```bash
# 开启水泵
curl -X POST http://localhost:8086/api/command \
  -H "Content-Type: application/json" \
  -d '{"device_name":"device","identifier":"F","value":1}'

# 关闭水泵
curl -X POST http://localhost:8086/api/command \
  -H "Content-Type: application/json" \
  -d '{"device_name":"device","identifier":"F","value":0}'

# 设置土壤湿度下限阈值
curl -X POST http://localhost:8086/api/command \
  -H "Content-Type: application/json" \
  -d '{"device_name":"device","identifier":"K","value":"30"}'

# 设置土壤湿度上限阈值
curl -X POST http://localhost:8086/api/command \
  -H "Content-Type: application/json" \
  -d '{"device_name":"device","identifier":"L","value":"70"}'

# 设置pH下限阈值
curl -X POST http://localhost:8086/api/command \
  -H "Content-Type: application/json" \
  -d '{"device_name":"device","identifier":"I","value":"5.5"}'
```

### Java (HttpClient)

```java
HttpClient client = HttpClient.newHttpClient();
String body = """
    {"device_name":"device","identifier":"F","value":1}
    """;
HttpRequest request = HttpRequest.newBuilder()
    .uri(URI.create("http://localhost:8086/api/command"))
    .header("Content-Type", "application/json")
    .POST(HttpRequest.BodyPublishers.ofString(body))
    .build();
HttpResponse<String> response = client.send(request, HttpResponse.BodyHandlers.ofString());
System.out.println(response.body());
```

### Python

```python
import requests

# 开启水泵
resp = requests.post("http://localhost:8086/api/command", json={
    "device_name": "device",
    "identifier": "F",
    "value": 1
})
print(resp.json())
```

## 校验规则

1. **device_name** 必填，必须在 `DeviceConfig.ALL_DEVICES` 中注册
2. **identifier** 必填，必须存在于目标设备的属性列表中
3. **value** 必填，不能为 null
4. 目标属性必须为"读写"模式，只读属性拒绝下发并返回可写属性列表
5. **类型自动转换**：
   - enum 类型属性：传入 `"0"` 或 `0` 均可，自动转为整数下发
   - int32 类型属性：传入 `"123"` 自动转为 `123`
   - string 类型属性：保持字符串

## 底层 OneNet API

后端最终调用的 OneNet 接口：

**POST** `https://iot-api.heclouds.com/thingmodel/set-device-desired-property`

**鉴权**：HMAC-SHA256（version=2022-05-01），使用设备 AccessKey 签名

**请求体**：
```json
{
  "product_id": "FeGVC46Lne",
  "device_name": "device",
  "params": {
    "F": 1
  }
}
```

**响应**：
```json
{
  "code": 0,
  "msg": "SUCCESS"
}
```
