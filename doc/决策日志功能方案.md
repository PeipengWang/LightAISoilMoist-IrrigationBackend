# 决策日志记录与查询功能方案

## 背景

当前系统已实现指令下发功能（`POST /api/command`），可对设备进行水泵开关控制（F）和阈值设置（I/J/K/L）。但每次指令下发后没有持久化记录，无法追溯历史操作。需要增加决策日志功能，记录每次指令下发并支持历史查询。

## 现状分析

当前指令下发调用链：

```
POST /api/command → DeviceController.apiCommand()
  → 校验(设备/属性/读写模式/类型)
  → OneNetApiClient.setDesiredProperty()
  → POST OneNet REST API
  → 返回结果给客户端
```

问题：返回结果后无任何持久化记录，操作历史不可追溯。

## 方案设计

### 1. 新增实体：DecisionLog

在 `model/entity` 下新建 `DecisionLog.java`，沿用项目现有的手写 getter/setter 风格（不使用 Lombok）。

| 字段 | 类型 | 说明 |
|------|------|------|
| id | Long (自增) | 主键 |
| deviceName | String(32) | 设备名 |
| identifier | String(16) | 属性标识符（F/I/J/K/L） |
| propertyName | String(32) | 属性中文名（如"水泵状态"） |
| value | String(64) | 下发的值 |
| valueDesc | String(64) | 枚举值说明（如"开启"/"关闭"，非枚举为空） |
| decisionType | String(16) | 决策类型：`PUMP_CONTROL`(水泵控制) / `THRESHOLD_SET`(阈值设置) |
| success | Boolean | 下发是否成功（基于 OneNet API 返回 code） |
| resultMsg | String(256) | OneNet API 返回的消息 |
| operator | String(64) | 操作来源，默认 "api" |
| createdAt | LocalDateTime | 记录时间 |

**decisionType 推断规则**：
- identifier = F → `PUMP_CONTROL`
- identifier = I/J/K/L → `THRESHOLD_SET`

### 2. 新增 Repository：DecisionLogRepository

```java
@Repository
public interface DecisionLogRepository extends JpaRepository<DecisionLog, Long> {
    // 按时间倒序分页查询
    Page<DecisionLog> findAllByOrderByCreatedAtDesc(Pageable pageable);
    
    // 按设备名查询
    Page<DecisionLog> findByDeviceNameOrderByCreatedAtDesc(String deviceName, Pageable pageable);
    
    // 按决策类型查询
    Page<DecisionLog> findByDecisionTypeOrderByCreatedAtDesc(String decisionType, Pageable pageable);
    
    // 按时间范围查询
    Page<DecisionLog> findByCreatedAtBetweenOrderByCreatedAtDesc(LocalDateTime start, LocalDateTime end, Pageable pageable);
}
```

### 3. DeviceController 改造

在 `apiCommand()` 方法中，OneNet API 调用返回后：

1. 解析 `result` 中的 `code` 判断成功/失败
2. 根据 identifier 推断 `decisionType`
3. 构建 `DecisionLog` 对象并调用 repository 保存
4. 保存失败不影响指令下发结果返回（catch 日志记录）

改造位置：`DeviceController.java` 第 284 行 `apiClient.setDesiredProperty()` 调用之后。

### 4. 新增查询 API

#### 4.1 GET /api/decision-logs

查询决策日志列表，支持多条件筛选和分页。

**请求参数**：

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| device_name | string | 否 | — | 按设备名筛选 |
| identifier | string | 否 | — | 按属性标识符筛选 |
| decision_type | string | 否 | — | `PUMP_CONTROL` 或 `THRESHOLD_SET` |
| start | long | 否 | 24小时前 | 起始毫秒时间戳 |
| end | long | 否 | 当前时间 | 结束毫秒时间戳 |
| page | int | 否 | 0 | 页码（0-based） |
| size | int | 否 | 20 | 每页条数（最大100） |

### 5. 数据流

```
POST /api/command → 校验 → OneNetApiClient.setDesiredProperty()
                                ↓
                          OneNet API 返回 result
                                ↓
                     ┌── 解析 result.code ──┐
                     ↓                       ↓
              构建 DecisionLog          构建 DecisionLog
              success=true              success=false
                     ↓                       ↓
              repository.save()        repository.save()
                     ↓                       ↓
              返回客户端（含日志）     返回客户端（含日志）


GET /api/decision-logs → DecisionLogRepository → 分页结果 → 返回客户端
```
