```yaml
    driver-class-name: org.h2.Driver
    username: sa
    password:
  h2:
    console:
      enabled: true
      path: /h2-console
  jpa:
    hibernate:
      ddl-auto: update
    show-sql: false
    open-in-view: false
    properties:
      hibernate:
        dialect: org.hibernate.dialect.H2Dialect
```

> `DB_CLOSE_DELAY=-1` 保证最后一个连接关闭后数据库进程不退出；`MODE=MySQL` 兼容 MySQL 语法便于日后迁移；`ddl-auto: update` 启动自动建表/加列，已存在的数据不丢失。

### 6.2 PhenologyService — 物候期自动判断

```java
@Service
public class PhenologyService {
    private final PhenologyStageRepository phenologyStageRepo;
    private final CropConfigRepository cropConfigRepo;

    // 手动覆盖的物候期（如果果农手动指定了当前阶段）
    private final ConcurrentHashMap<Long, Long> manualOverride = new ConcurrentHashMap<>();

    /**
     * 判断当前物候期。
     * 优先级：手动指定 > 积温计算 > 按月份粗略判断
     */
    public PhenologyStage determineCurrentStage() {
        CropConfig crop = cropConfigRepo.findByIsActiveTrue().orElse(null);
        if (crop == null) return null;

        // 1. 手动覆盖检查
        Long overrideStageId = manualOverride.get(crop.getId());
        if (overrideStageId != null) {
            return phenologyStageRepo.findById(overrideStageId).orElse(null);
        }

        // 2. 尝试用积温（GDD）判断 — 一期暂无实时积温数据源，后续接入
        // BigDecimal currentGdd = calculateGdd();
        // if (currentGdd != null) { ... }

        // 3. 按当前月份粗略判断
        int month = LocalDate.now().getMonthValue();
        return phenologyStageRepo.findByCropIdAndMonth(crop.getId(), month).orElse(null);
    }

    /**
     * 手动设置当前物候期
     */
    public void overrideStage(Long cropId, Long stageId) {
        manualOverride.put(cropId, stageId);
    }

    /**
     * 取消手动设置
     */
    public void clearOverride(Long cropId) {
        manualOverride.remove(cropId);
    }
}
```

### 6.3 ThresholdService — 阈值查询 + CRUD

```java
@Service
public class ThresholdService {
    private final StageThresholdRepository thresholdRepo;
    private final ThresholdSnapshotRepository snapshotRepo;
    private final PhenologyService phenologyService;
    private final SoilConfigRepository soilConfigRepo;

    /**
     * 查询当前生效的有效阈值。
     * 对每个属性，先查 "物候期 + 指定土壤" 的阈值，找不到则用 "物候期 + 通用土壤" 兜底。
     */
    public Map<String, Map<String, BigDecimal>> getCurrentThresholds(String soilType) {
        PhenologyStage stage = phenologyService.determineCurrentStage();
        if (stage == null) return Collections.emptyMap();

        SoilConfig soil = null;
        if (soilType != null) {
            soil = soilConfigRepo.findBySoilType(soilType).orElse(null);
        }

        // 查该阶段的全部阈值
        List<StageThreshold> all = thresholdRepo.findByPhenologyStageIdAndIsActiveTrue(stage.getId());

        // 按属性分组，土壤特定 > 通用兜底
        Map<String, Map<String, BigDecimal>> result = new LinkedHashMap<>();
        for (StageThreshold t : all) {
            String prop = t.getPropertyIdentifier();
            boolean matches = (soil != null && t.getSoilConfig() != null
                    && t.getSoilConfig().getId().equals(soil.getId()))
                    || t.getSoilConfig() == null;
            if (!matches) continue;

            Map<String, BigDecimal> propMap = result.computeIfAbsent(prop, k -> new LinkedHashMap<>());
            propMap.put(t.getThresholdType(), applySoilCorrection(t, soil));
        }
        return result;
    }

    /**
     * 应用土壤修正系数
     */
    private BigDecimal applySoilCorrection(StageThreshold threshold, SoilConfig soil) {
        if (soil == null || soil.getMoistureCorrectionFactor() == null) {
            return threshold.getThresholdValue();
        }
        // 仅对湿度类阈值应用修正
        if ("B".equals(threshold.getPropertyIdentifier()) || "D".equals(threshold.getPropertyIdentifier())) {
            return threshold.getThresholdValue().multiply(soil.getMoistureCorrectionFactor());
        }
        return threshold.getThresholdValue();
    }

    // ===== CRUD =====

    public StageThreshold updateThreshold(Long id, BigDecimal newValue, String reason, String operator) {
        StageThreshold t = thresholdRepo.findById(id).orElseThrow();
        BigDecimal old = t.getThresholdValue();
        t.setThresholdValue(newValue);
        t.setUpdatedAt(LocalDateTime.now());
        thresholdRepo.save(t);

        // 记录快照
        ThresholdSnapshot snap = new ThresholdSnapshot();
        snap.setStageThresholdId(id);
        snap.setOldValue(old);
        snap.setNewValue(newValue);
        snap.setChangeReason(reason);
        snap.setChangeSource("MANUAL");
        snap.setOperator(operator);
        snapshotRepo.save(snap);

        return t;
    }

    public List<ThresholdSnapshot> getHistory(Long thresholdId) {
        return snapshotRepo.findByStageThresholdIdOrderByChangedAtDesc(thresholdId);
    }

    public List<StageThreshold> getStageThresholds(Long stageId) {
        return thresholdRepo.findByPhenologyStageIdAndIsActiveTrue(stageId);
    }

    public List<PhenologyStage> getStages() {
        CropConfig crop = cropConfigRepo.findByIsActiveTrue().orElse(null);
        if (crop == null) return Collections.emptyList();
        return phenologyStageRepo.findByCropConfigIdOrderByStageOrderAsc(crop.getId());
    }
}
```

### 7.1 ThresholdController

```java
@RestController
@RequestMapping("/api/thresholds")
@Tag(name = "阈值管理", description = "物候期阈值配置与查询")
public class ThresholdController {
    private final ThresholdService thresholdService;
    private final PhenologyService phenologyService;

    // GET  /api/thresholds/current?soilType=LOAM
    //      查询当前物候期下生效的全部阈值（自动判断物候期）
    @GetMapping("/current")
    @Operation(summary = "查询当前生效阈值")
    public Result<Map<String, Object>> getCurrentThresholds(
            @Parameter(description = "土壤类型") @RequestParam(required = false, defaultValue = "LOAM") String soilType) {

        PhenologyStage stage = phenologyService.determineCurrentStage();
        Map<String, Map<String, BigDecimal>> thresholds = thresholdService.getCurrentThresholds(soilType);

        Map<String, Object> data = new LinkedHashMap<>();
        data.put("stage", Map.of("name", stage.getStageName(), "order", stage.getStageOrder()));
        data.put("soilType", soilType);
        data.put("thresholds", thresholds);
        return Result.success(data);
    }

    // GET  /api/thresholds/stages
    //      查询所有物候期列表
    @GetMapping("/stages")
    @Operation(summary = "查询物候期列表")
    public Result<List<Map<String, Object>>> getStages() {
```

## 九、技术要点说明

### 9.1 为什么是 H2DB 文件模式而非内存模式

| 对比项 | 内存模式 (mem) | 文件模式 (file) |
|--------|---------------|----------------|
| 重启后数据 | 丢失 | 保留 |
| 用户修改的阈值 | 每次重启需重新设置 | 持久化保留 |
| 适合场景 | 开发/测试/演示 | **生产级配置管理** |

选用 `jdbc:h2:file:./data/threshold_db`，数据文件落盘在项目 `data/` 目录下，重启后阈值配置不丢失。

### 9.2 ddl-auto: update 的行为

- **首次启动**：Hibernate 自动扫描 `@Entity` 类并创建所有表
- **后续启动**：如果实体新增了字段，自动在表里加列（ALTER TABLE ADD COLUMN）
- **不会删除已有列或数据**（与 `create` / `create-drop` 的核心区别）
- **不会修改已有列的类型或约束**（需要手动迁移）

### 9.3 阈值查询的土壤修正二层查找逻辑

```
查询 humidity_lower for 膨大期 + SAND:
  1. 查 stage_threshold WHERE phenology_stage=膨大期 AND soil_config=SAND → 无结果
  2. 查 stage_threshold WHERE phenology_stage=膨大期 AND soil_config IS NULL → 命中
  3. 拿到基准值 65% → × 0.7 (SAND修正系数) → 返回 45.5%
```

这样只需为 LOAM（基准土壤）存储 7×7=49 条阈值记录，其他 4 种土壤通过修正系数自动算出，避免数据膨胀。

### 9.4 物候期判断算法

一期使用按月份粗略判断（当前日期 → 查询 `typicalStartMonth ≤ month ≤ typicalEndMonth`）。

跨年物候期（如休眠期 11月→次年2月）的特殊处理：
```sql
WHERE (typical_start <= typical_end AND :month BETWEEN typical_start AND typical_end)
   OR (typical_start > typical_end AND (:month >= typical_start OR :month <= typical_end))
```

后续二期接入积温计算后，替换为 `GDD >= gdd_threshold_low AND GDD < gdd_threshold_high`。

### 9.5 与现有系统零耦合

一期实现完全独立，不修改任何现有代码（除了 pom.xml 和 application.yml 的追加）。现有 DeviceDataManager、DeviceController、SSE 推送全部不动。后续二期通过 DeviceDataManager 的数据刷新钩子与告警引擎对接。
